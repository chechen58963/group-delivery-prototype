# 수령 이동거리 누적 포인트

## 기존 DB 업데이트

기존 공동배달 과정 확장까지 적용한 프로젝트에서는 SQL Editor에서
`walking-rewards.sql` 전체만 실행하면 됩니다. 기존 모임·계정·송금 기록을 변경하지 않습니다.
새 DB에서는 `setup.sql` → `menu-discovery.sql` → 최신 `APPLY-UPDATES.sql` 순서로 실행합니다.

## 동작

- 앱 안에서 모으는 체험 포인트입니다. 현금·할인·실제 걸음 수와 연결하지 않습니다.
- 각 모임의 편도 예상 이동거리를 수령 전에 등록합니다.
- 출발점과 수령점의 좌표가 있으면 직선거리 예상치를 사용하고, 없으면 직접 입력합니다.
- 모임당 0~400m를 누적합니다. 내 근처 수령 요청자가 되면 그 모임은 0m로 처리합니다.
- 전원이 직접 수령을 확인해 거래가 완료될 때만 본인 계정에 거리를 더합니다.
- 누적 거리가 1,000m를 넘을 때마다 100P를 지급합니다. 초과 거리는 다음 보상에 이어집니다.
- 350m × 3회 → 누적 1,050m, 100P 지급, 다음 보상 진행도 50/1,000m.
- 다시 950m를 더 누적하면 총 2,000m, 100P 추가 지급.
- 취소·탈퇴한 모임은 누적하지 않고 수령 후 거리를 바꿀 수 없습니다.
- 각 사용자/모임의 원장은 하나뿐이며, 반복 요청·새로고침·SQL 재실행으로 중복 지급하지 않습니다.
- 계획·원장은 본인만 조회합니다. 포인트 계산은 서버의 완료 처리에서 수행합니다.
- 기존에 끝난 모임을 소급 적립하지 않습니다.

## 화면

메뉴/배달/수령 화면의 ‘수령 이동 포인트’에서 예상 거리를 등록합니다.
완료 화면에서 이번 누적 거리를 보고, 내 정보의 ‘나의 이동 포인트’에서
총 거리·포인트·다음 보상까지의 진행률과 상세 내역을 확인합니다.

거리와 포인트의 기준은 `src/walkRewards.ts`와 이 SQL의 상수에 있습니다.
향후 비율을 바꾼다면 두 파일을 함께 변경하고, 기존 원장을 보존하는 별도 이전 정책을 정해야 합니다.
