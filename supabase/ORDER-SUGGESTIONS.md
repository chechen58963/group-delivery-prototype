# 메뉴 선호 기반 주문 제안

`APPLY-ORDER-TIMING.sql` 적용 후 `APPLY-ORDER-SUGGESTIONS.sql` 전체를 실행합니다. 완료 문구는 `주문 조합 제안 업데이트 적용 완료`입니다.

- 기존 관심 메뉴 알림, 모집과 수락, 채팅, 송금·환불, 수령, 포인트 기록을 보존합니다.
- 새 조건은 원하는 가게·메뉴·수량과 `exact / brand / similar` 타협 범위입니다. `brand`는 같은 메뉴 분류가 있는 가게만, `similar`는 같은 카테고리 안에서 제안합니다. 간식은 주메뉴의 대체품으로 제안하지 않습니다.
- `지금 주문 가능`은 서버 저장 시점부터 15분 동안 유효합니다. 자동으로 연장하지 않습니다.
- 두 명의 조건과 시간대가 겹치고, 양쪽에서 각각 직선 400m 이내인 공개 장소가 있을 때 제안합니다. 상대 출발 좌표는 반환하지 않습니다.
- 예상 배달비는 3,000원을 두 명이 나눈 값입니다. 부족한 목표금액을 별도로 안내하고, 실제 모집 준비에서 메뉴와 조건을 검토합니다.
- 제안을 눌러도 상대를 자동 참가시키지 않습니다. 최신 조건을 다시 확인한 뒤 모집 초안을 열고, 이후 신청·리더 수락 절차를 사용합니다.
- 업데이트 전 관심 메뉴만 등록한 사람은 새 화면에서 구체적인 메뉴와 타협 범위를 저장해야 새 조합 제안에 포함됩니다.

검사: `node tests/order-suggestions-db.mjs`, `node tests/virtual-gps-db.mjs`, `node --test tests/*.test.mjs`, TypeScript 및 Vite 빌드.
