# 배프.v2 UI/UX 미리보기

- 기존 앱: `/`
- 새 버전: `/v2/`
- 개발: 실행 중인 Vite 서버의 `/v2/`로 접속
- 배포: 기존 `build` 명령이 두 HTML 진입점을 함께 생성

## 분리 원칙

`src/v2/`는 기존 앱 컴포넌트, 전역 스타일, 인증·Supabase 클라이언트를 가져오지 않습니다. 기존 가게·메뉴·사진 자료만 읽습니다. 기존 앱의 사용자, 주문, 포인트 및 DB를 수정하지 않습니다.

화면 상태는 탭별 `sessionStorage`의 `baef-v2-ui-v1` 키에 저장됩니다. 로그인 없이 참가자·리더 흐름을 둘러볼 수 있습니다. 새 탭에서 열면 새 체험을 시작할 수 있습니다.

## 체험 흐름

1. 참가자: 모집글 → 메뉴 담기 → 신청 → 수령 방법 확인 → 송금 표시 → 배달 → 수령 → 후기
2. 리더: 가게 선택 → 메뉴 담기 → 모집 조건 → 신청자 프로필·후기 확인 → 수락 → 계좌 입력 → 주문 확정 → 입금 확인 → 배달 → 수령
3. 채팅, 위치 선택, 수령 방법 제안, 관심 메뉴 알림, 포인트 상점, 프로필, 테마도 연결되어 있습니다.

상대방의 신청·응답·수령은 1~3초 후 자동으로 전환되는 화면 시나리오입니다. 리더 시나리오는 직접 신청을 수락해야 진행됩니다. 가상의 상대는 한 명이며 모집 인원 선택 화면은 2~5명을 표시합니다. 지도는 외부 지도 연동 없이 UI 확인을 위한 캠퍼스 그림입니다. 송금·주문·상품 교환은 외부 서비스를 호출하지 않습니다.

## 검증

`npx tsc --noEmit`와 `npm run build`로 기존 앱과 v2를 함께 검사할 수 있습니다. 스타일은 `v2.css`에서 독립적으로 관리합니다.
